# Prologo
Un libro mas enfocado en darte consejos y contarte experiencias a la hora de producir software, mas que bombardearte de conceptos, técnicas, etc.
Entra diciéndonos que no existe un lenguaje, sistema, diseño, arquitectura o metodologia perfectos, que cada uno esta echo para solucionar un o unos problemas específicos y no para solucionarte todos.
Es la experiencia la que nos dicta cuales son las herramientas que se adaptan mejor para solucionar el problema que se nos presenta, no podemos casarnos con una sola tecnologia y estar siempre abiertos a expandir nuestros conocimientos, a no estrechar la mirada a la hora de buscar soluciones a los problemas.
